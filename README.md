The MultiBoi is an Open Sourced Multi functional Board for multiple different game consoles, With the Raspberry Pi Pico at the heart of it. I'ts purpose is geared towards being a repair tool.
So if your fixing game systems pretty regularly or would like to have a all-in-one type of tool. This is it! 

MultiBoi is built for 
* Wii U De_fused (and can be used for UDPIH)
* Xbox 360 Pico Flasher (both Regular and 4GB NAND)
* OGX Mini (use multiple different controllers with different consoles)
* UART Bridge (Uart0/Uart1 available.. Diagnose ps4/ps5 or anything that uses UART)


The MultiBoi must be programmed everytime to use it for what you need. 
For example, you need UART? Program UART bridge .uf2
* Wii U De_fused: https://github.com/StroopwafelCFW/wii_u_modchip
* OGX MINI:       https://github.com/wiredopposite/OGX-Mini
* Pico Flasher:   https://github.com/X360Tools/PicoFlasher
* UART Bridge:    https://github.com/Noltari/pico-uart-bridge

*** specific to Wii U & Pico flasher ***
Flip all switches to ON for Wii U and OFF for Xbox 360 

***** WARNING : USB 2.0 PORT MUST BE SOLDERED
***+* ON THE BOTTOM OF THE BOARD !!!!
